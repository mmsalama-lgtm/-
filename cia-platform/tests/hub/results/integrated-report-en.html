    Method notes

    • The overall index and each tool's index are what the platform dashboard computes, by the same rules (the mean of the indices of the tools selected for the index).
    • Each tool's results are read through the platform's reader for that tool, never recomputed by a different rule.
    • Open items are read by each tool's own rules: the ISO toolkits' action plans, actions with an owner, date and status, and the toolbox tools' follow-up flags.
    • Roadmap order = severity × overdue × number of systems the item touches; an item shared by several tools appears once with every tool it closes.
