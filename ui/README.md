# تنسيق الواجهة (`tools/polish_ui.py`)

يضيف إلى المنصة تنسيقاً دون تغيير أي محتوى:

- **القائمة:** زر «القائمة» (☰) في كل المقاسات بدل الشريط العلوي الذي كانت بعض عناصره تختفي. يفتح كل الأقسام في ثلاث مجموعات (ابدأ · اعمل على منشأتك · تعلّم وتواصل) مع أيقونة لكل قسم. وأي قسم جديد تضيفه إلى `UI.ar.nav` يظهر تلقائياً في المجموعة الأخيرة.
- **الصفحة الرئيسية:** كل منظومة في «كل الأدوات في مكان واحد» وكل مجموعة في «المراجع الرسمية» تعرض صفاً واحداً وزر «عرض الكل (n)». الفلترة حسب الدور تعرض كل النتائج. والمرجع الذي تستخدمه أدوات كثيرة يعرض 6 منها وزر «+n». ورابط «المصدر» من بطاقة أداة يفتح مجموعة المرجع تلقائياً.
- **الأدوات (39) — طبقة تصميم موحّدة:**
  - البطاقة الافتتاحية أصغر، والشعار بجانب العنوان على الشاشات الواسعة.
  - رأس كل قسم: أيقونة القسم (نفسها التي في القائمة الجانبية) بجانب العنوان، والوصف تحت العنوان لا بجانبه، وخط فاصل تحته.
  - البطاقات بظل خفيف ومساحة داخلية أكبر، والبطاقات القابلة للضغط ترتفع قليلاً عند المرور.
  - حدود الحقول أوضح، وأسماء الحقول بخط أثقل، وارتفاع موحّد (44px) لحقول النماذج.
  - الأزرار الصغيرة والشرائح أكبر قليلاً لسهولة الضغط، وإطار تركيز ذهبي واضح عند التنقل بلوحة المفاتيح.
  - «لا توجد بيانات بعد» بإطار منقّط واضح بدل صندوق فارغ.

الملفات: `ui/ui.css` و`ui/ui.js` (الصفحة الرئيسية)، و`ui/tool.css` و`ui/tool.js` (الأدوات).

## الترتيب عند تجهيز نسخة جديدة

```
python3 -I tools/apply_review_fixes.py <مجلد-المنصة>
python3 -I tools/polish_ui.py <مجلد-المنصة>
python3 -I tools/add_certs.py <مجلد-المنصة>
python3 -I tools/add_cloud.py <مجلد-المنصة>
python3 -I tools/add_pwa.py <مجلد-المنصة>     # دائماً الأخير
```

كل سكربت يمكن تشغيله مرة أخرى على نتيجته، ويتوقف دون أن يكتب شيئاً إذا تغيّر الكود الذي يعتمد عليه.
